Hypothesis Comparison: Concept B vs. Concept A

Dimension Concept A (Editorial North Star) Concept B (Quiet Modular Hypothesis)
Primary Goal Editorial magazine aesthetic; title-first visual showcase. Task execution efficiency across all 5 e-reader screens.
Navigation Model Hidden drawer via top-right masthead icon (2 taps). Persistent 4-tab bottom hub (1 tap everywhere). Testable hypothesis.
Reachability Key triggers at top glass bezel (Y: 0..40). High risk of GT911 edge misses. Primary controls placed in lower reach zone (Y: 744..800). All touch targets ≥44px (important targets 56px).
Empty State Static layout: swaps text to "Your Library is Waiting". Dynamic reorganization into an Onboarding Ingestion Canvas with direct Web Server and SD actions.
Screen Scope Home Screen only. 5 connected screens: Home, Library, Reader, Files, Settings.

Adherence to E-Paper Constraints

  • Pure 1-Bit Palette: Solid black (#000) and pure paper (#FFF) with hairline dividers; no blur or gradients.
  • Zero Sliding Transitions: State changes mimic discrete e-paper waveform cycles.
  • Vietnamese Typography: Multi-line titles and diacritics rendered with safe line height to prevent glyph clipping.
