## Experiment Rules

1. Experiments must be self-contained within their respective subdirectories.
2. An experiment must never modify approved production baselines (e.g. Concept A / `home-v1.1.html` / `X4ProHomeLayout.h`).
3. Simulated interactions, browser timings, or task approximations must be clearly demarcated in each experiment's `QA.md`.
