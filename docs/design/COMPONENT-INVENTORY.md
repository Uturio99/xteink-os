## Component contract matrix

The [semantic architecture and state contract](DESIGN-SYSTEM-V2-PROPOSAL.md#semantic-architecture) defines shared states. Every interactive row below inherits the `target` minimum on both axes, `s2` separation from adjacent targets, visible `focus`, and transient press feedback. The gallery uses its existing anchors to demonstrate destinations and local buttons to demonstrate commands.

| Intent / role | Components and placement | Interaction and state | Visual tokens and usage |
|---|---|---|---|
| Move to a root destination · Navigation | Home, Library, Settings in their root rails | Named links. Exactly one current destination per rail. Keyboard focus can sit on a different link. No selected or disabled link style in the gallery | Borderless `nav-link`, `target`, `s2` gaps, current underline `selected-rule`. Rail uses `edge`. Root rail placement is a separate PO decision |
| Return to the caller · Navigation | Reader Back to Library, Import Back to Home | Upper-left named Back. Gallery links jump to the indicated specimen. Product Back restores caller context per NAV-001 and Import/Settings contracts. No persistent selected state. If a safe operation blocks exit, communicate why | Borderless `nav-link`, `target`, `s2` padding, `icon` cue. One Back per child header. Independent Home remains separate |
| Switch view · Navigation + Selection | Three provisional Library tabs | Tablist with linked panels and one selected tab. Roving keyboard stop, arrows/Home/End activate views, tap activates one. Focus, transient press and selected underline are separate. No disabled tab in the gallery | `tab-h`, `s2`, `selected-rule` underline. **PROPOSED** borderless tabs. Keep neutral labels until PO maps the views |
| Open content · Navigation | Recent and catalog book rows; review-only Import link | One link target per row or inline destination. Open the indicated item in product. Gallery book rows jump to one sample Reader. No persistent selection from opening a book | `structure` and `edge` divider on rows, `recent-w/h`, `cover-w/h` and `book-h`. Inline link is borderless with underline. Chevron is decorative |
| Open service/settings detail · Navigation | Display, Controls, Network, OPDS, Extensions | One full row target. Product opens the child and Back restores the row and viewport. Gallery buttons show preview feedback. Unavailable service uses a clear reason | `structure`, `edge`, `setting-h`, `setting` label, `meta` detail, `icon` chevron. Keep grouped sections |
| Run main task · Action | Resume, primary example | Run the labeled command. Resume restores stored reading state in product and uses a specimen jump in the gallery. No persistent selected state | `pill`, `action-h`, `body`, `s4`, ink fill with paper text. One primary per decision |
| Run supporting task · Action | Clear search, open dialog, keep editing, local/Wi-Fi/USB Import source controls | Clear restores Search focus. Dialog trigger opens the overlay. Import controls begin their named route or report preview feedback. Unsupported USB cannot activate | `pill`, `action-h` or compact `target` for Clear, `body`, `s4`, outlined `edge`. Unavailable action keeps the outline and has a reason |
| Confirm a destructive task · Action | Discard changes in sample dialog | Name the consequence. Require confirmation with safe initial focus on Keep editing. Activation only after explicit confirmation | Same `pill` and monochrome action tokens. Use wording and placement to show consequence |
| Invoke a compact command · Action | Refresh icon specimen | Accessible name and a single target. No selected state. The gallery reports feedback instead of performing a device refresh | `circle`, `target` × `target`, `icon`, `edge` |
| Enter text · Inputs / Controls | Library Search, text and invalid input fixtures | Persistent label, normal text editing, keyboard and touch focus. Search uses a derived matching key. Invalid keeps its value and explanation. Separate Clear command when populated | `pill`, `target`, `s4`, `edge`; heavier invalid border from `focus`. Text retains language and normalization |
| Choose a value · Inputs / Controls + Selection | Library Sort, disabled select, native option list | One labeled native Select. Options expose selected value. Keyboard and touch use native choice interaction. Disabled trigger gives context and cannot open | Closed trigger uses `pill`, `target`, `s4`, `icon`. Browser owns expanded option geometry. Separate sort stays provisional pending tab mapping |
| Set on/off · Inputs / Controls | 1-bit palette preview toggle | Button exposes on/off with `aria-pressed`. Persistent on state is distinct from pointer press and keyboard focus. Review control outside the device screen | `pill`, `action-h`, `edge`. Selected ink fill and paper text |
| Read editorial information · Content / Data | Headings, book hero, covers, book metadata, settings groups, Reader text | Read-only text and artwork. Covers inside links remain part of the parent row. Preserve English UI and Vietnamese NFC/NFD source content | `structure`, existing `display`, `hero-title`, `book-title`, `reader`, `meta` and spacing/cover tokens |
| Inspect status or progress · Content / Data | Battery, clock, reading progress, Reader footer | Read-only. Native progress/label in browser. Battery immediately before far-right time. Position and percentage require reliable values in product | `meta`, `battery-w/h`, `s2`, `edge`, `selected-rule` for track, `structure` |
| Understand outcome · Feedback | Loading, empty, no matches, unavailable, error, success and inline feedback | Stable message and safe recovery where relevant. Announce meaningful status updates without taking focus. Loading does not represent a selected state | `structure`, `body`, `s3`, `edge`. Any recovery control uses its own navigation or action role |
| Resolve an interruption · Feedback / Overlays | Confirmation dialog and backdrop | Named modal with safe initial focus. Trap interaction, Escape cancels, restore focus to opener. Confirm and cancel retain command semantics | Shared `dialog-radius`, `s5`, `edge`, normal action tokens. Stable 1-bit state |
