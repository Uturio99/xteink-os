## Native component contract

Map **intent → semantic role → behavior → existing owner → tokens**. Use current `ThemeMetrics` → `uiThemeTokens()` and existing rendering/input primitives; introduce only the smallest missing values after checking the pinned SDK. CSS pixel values are targets for the 480×800 logical portrait composition, not device-proven metrics.

| Role / V2 target | Native owner and minimum integration | Acceptance boundary |
| --- | --- | --- |
| Frame, typography, monochrome | `UITheme`, `ThemeMetrics`, `BaseTheme`, renderer and existing Noto/EpdFont assets. Carry the V2 480×800 frame, named insets/spacing, serif heading and sans controls as theme values; do not copy browser font metrics verbatim. | Check actual board safe area, 1-bit contrast, RAM/framebuffer and Vietnamese NFC/NFD glyph layout before fixing native font IDs. Preserve source text; normalize only derived search keys. |
| Root navigation and contextual Back | `ActivityManager`, `Activity`/`UiListActivity`, `BaseTheme` header, `MappedInputManager`. Root destinations are borderless; Back is upper-left and borderless. Keep the existing independent Home event. | Back and Home are separate commands; no invented gesture. Verify touch, button short/hold/release and modal ownership. |
| Home hero, Resume, recent shelf | `HomeActivity`, `CoverGridHomeUi`, `RecentBooksStore`, existing progress/Reader route. Recompose presentation around live book identity and progress; retain all existing Home destinations. | Journey A, missing-book recovery, no duplicate progress source or book-cache mutation. |
| Library tabs, Search, book rows | `LibraryListActivity`, `UiTabListActivity`, library index and existing search. Keep Recent/Title/Author and per-mode direction. Borderless tabs with active indicator; editorial rows/dividers rather than pill cards. | Search/query, sort, selected identity, scroll anchor and focus survive Reader round-trip (NAV-001); long-list and missing-item fallback. |
| Primary/secondary actions, Search/Select, icon controls | Existing `fui::` controls/`UIThemeTokens.h` where supported. Full-pill action and closed input/Select targets; circular icon-only targets; at least 44 logical px and 8 px separation. | Confirm exact control API and hit geometry from pinned SDK; focus, pressed, selected and disabled remain distinct in 1-bit output. |
| Reader, status and progress | `ReaderActivity`, `EpubReaderActivity`, `XtcReaderActivity`, `BaseTheme::drawStatusBar`, `HalClock` path already used by `BaseTheme.cpp:383–386,901–915`. Battery immediately left of far-right time; footer Page X / Y left, Z% right when reliable. | `EpubReaderActivity.cpp:317,2469` uses estimated page counts; never present those as exact book totals. XTC has page count (`XtcReaderActivity.cpp:73–96`). Use a position-only fallback when total is unreliable. Keep TOC, settings, refresh and native clock behavior. |
| Settings and child services | `SettingsListActivity`, `SettingsActivity`, service activities. Editorial grouped rows; 12 px dialog container, normal action geometry. Reuse `startActivityForResult` for child return where already present. | Journey D restores section/selection/focus and does not hide Display, Controls, Network, OPDS, Plugins or recovery routes. |
| Import, feedback, recovery | `FileBrowserActivity`, `CrossPointWebServerActivity`/server, `UsbDriveActivity`, existing popup/confirmation components. Capability-gate USB. | Wi-Fi success requires completed write/close and rescan before Open Library; USB requires safe eject, SD handoff and native restart to Home. Browser success screens are not device proof. Preserve partial-upload cleanup and retry/error paths. |

**Minimum token set:** frame/safe insets; `paper/ink/muted/rule` with 1-bit proof; type roles (heading/body/meta/Reader); spacing steps and only named composition exceptions; target/action/tab/row heights; pill/circle/dialog-12/structural radii; line weight; focus/selected/disabled treatments. Source targets are in `DESIGN-SYSTEM-V2-PROPOSAL.md:16–26,31–38,42–76`. Reuse `ThemeMetrics` and `uiThemeTokens()`; do not create a second theme registry. Color/shape tokens must map to actual native draw and hit regions, not just decoration.
