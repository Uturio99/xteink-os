Visual North Star Architecture

The v1.0 specification supersedes earlier wireframes with a commanding literary aesthetic:

  • Centered Editorial Hero: Centered 116×174px cover artwork positioned directly above dominant 21pt serif title and 13pt italic author credit.
  • Refined Hairline Progress: Slender 3px progress track (140×3px) with high-contrast completion stats. Omitted gracefully if progress < 0.
  • Apple HIG Action Button: Centered 210×44px Continue Reading → button guaranteeing ergonomic one-handed touch activation.
  • 3-Book Secondary Shelf: Maximum 3 books (84×126px thumbnails) with distinct progress pills and truncated titles.
  • Quiet Masthead & Minimal Footer: 42px top bar with search/settings; 56px bottom ribbon with Library (24) and Files (SD Card). Zero 5-item mobile docks.
  • Pure 1-Bit Supremacy: Solid black ink on white paper. No fake shadows, gradients, or skeletal card frames.

Hardware Validation Checklist (X4 Pro Bench Units)

  • Touch GT911 Edge Sensitivity: Validate top masthead (Search/Settings) and bottom footer buttons register cleanly without edge deadzones.
  • Display 1-Bit Controller Waveforms: Validate 1px hairline rules and partial refresh updates across SSD1677 / UC8179 controller batches.
  • Hardware Key Home Button Policy: Governed by HomeButtonSettings.h. Does NOT force automatic full refresh.
